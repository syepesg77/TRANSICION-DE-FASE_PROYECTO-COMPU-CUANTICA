# TRANSICION-DE-FASE_PROYECTO-COMPU-CUANTICA
Este proyecto implementa una simulación numérica de la Transición de Fase Inducida por Medida (MIPT) en circuitos cuánticos aleatorios 1D. La MIPT es un fenómeno fascinante donde el acto de medir un sistema cuántico puede, por sí solo, provocar un cambio de fase abrupto en sus propiedades de entrelazamiento.
